# Problem Statement: Personal Finance Tracker

## Problem Statement
Individuals often struggle to keep track of their monthly spending across different categories, leading to budget overruns and poor financial awareness.

## Target Users
College students, freelancers, and individuals seeking a simple command-line interface tool to monitor budgets and track personal cash flows.

## Core Features
1. User profile and budget threshold management.
2. Complete CRUD management for Income and Expense entries.
3. Automated real-time analytics for budget tracking and status alerts.
