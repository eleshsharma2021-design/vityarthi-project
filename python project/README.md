# Personal Finance & Expense Tracker

> **Vityarthi Project** | VIT Bhopal University

A modern, full-stack personal finance and expense tracking application designed to help users track spending, set budgets, analyze income vs. expenses, and gain visual insights into their financial health.

---

## 📌 Project Overview

Managing personal finances effectively requires clarity and consistency. This application addresses common budget tracking challenges by allowing users to seamlessly log transactions, categorize expenses, track income sources, and view graphical analytical reports.

### Key Features
* 💳 **Transaction Logging:** Track both income and expenses with customizable tags, categories, and dates.
* 📊 **Interactive Dashboard:** Visual break-downs of monthly spending using dynamic charts and summaries.
* 🎯 **Budget Management:** Set categorical spending limits and receive alerts when nearing thresholds.
* 📑 **Reports & Exports:** Generate structured financial statements and summary reports.
* 🔒 **Secure Authentication:** Account protection for user-specific financial data.
